## Реальный HTTPS smoke

Использованы ранее разрешённые временные user services и одноразовая БД
`sopds_m06_https_probe_20260925` с копией библиотеки из
[M06.5g](m06-https-probe.md). Gunicorn перечитал код через SIGHUP. Caddy,
корневой CA, настройки БД и исходные книги не менялись.

Клиент Python urllib явно доверял публичному CA Caddy, проверял сертификат
и IP, без исключений TLS. С этого Ubuntu-хоста через
`https://192.168.88.44:8443` получены:

- HTTP 200: `/web/`, `/web/login/`, web-поиск, `/opds/`, OPDS-поиск,
  static, `/opds/download/1/0/`, `/opds/view_html/1/`.
- Скачивание совпало побайтно с искусственным `m06-restore-probe.fb2` из
  копии библиотеки. Preview содержит CSP sandbox и `SAMEORIGIN`.
- Некорректный page дал 400, отсутствующая книга — 404.
- HSTS отсутствует. После preview временный каталог имеет `0700` и пуст.

Первый HTTPS smoke после 159 тестов выявил отсутствующий temp-каталог;
исправление проверено отдельно и повторным полным набором из 160 тестов.
Это показывает предел прежних тестов: они всегда заранее создавали temp.
