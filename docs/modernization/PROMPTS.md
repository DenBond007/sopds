## M00 — первое задание

Прочитай AGENTS.md, docs/modernization/STATE.md и PLAN.md.
Выполни только M00: подготовь проверяемое исходное состояние SOPDS в этой Ubuntu VM.
Не начинай массовое обновление зависимостей и не переходи к M01.

Сначала проверь Git и окружение; уточни текущую ветку и исходный SHA.
Посмотри локальную подготовку в scripts/dev/prepare-local.py и infra/dev-db/compose.yaml.
Контейнером управляет человек. Используй только отдельную dev-БД,
загружая `.local/dev.env` без вывода её содержимого.
Секреты Codex/GitHub, SSH private keys и `.local/postgres.env` не читать.

Определи совместимый Python для исходной версии. Не устанавливай старые requirements
в Python 3.13. При необходимости создай отдельное старое .venv, не изменяя системный Python.
Не считай отсутствие старого интерпретатора поводом для многократных бесплодных попыток:
после диагностики покажи точный блокер и минимальные действия человека.

Запусти исходные тесты, сохрани команды, результаты и ошибки в baseline.md.
Добавь повторяемые команды безопасного dev-запуска и проверок. Явно настрой
SOPDS_ROOT_LIB на тестовую `.local/library`; SOPDS_DEV_LIBRARY сама по себе старым
приложением не используется. Не подключай рабочую библиотеку и production-БД.
Если зависимости, системные пакеты или сеть требуют разрешений — запрашивай их,
не обходи sandbox и не выполняй sudo. Самостоятельно сформируй необходимые подзадачи.

Обнови PLAN.md и STATE.md. Разрешён локальный коммит собственных проверенных изменений.
Не выполняй push, PR, merge, выпуск или deployment. Остановись после M00 либо блокера.
В отчёте: выполненные проверки, исходные сбои, команды запуска и следующий шаг.
