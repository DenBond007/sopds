# M05: результат проверки кандидата

## Подтверждено локально

- Целевое окружение: Python 3.13, Django 5.2 LTS, PostgreSQL 17 и зависимости
  из `uv.lock`. Локальный `uv sync --frozen --offline` завершился успешно.
- На новой одноразовой test-БД прошли 131/131 Django-тестов. `manage.py check`
  не сообщил замечаний, `makemigrations --check --dry-run` не нашёл изменений.
- Синтетическая запись из схемы `opds_catalog.0001` прошла миграции до `0005`
  с сохранением ID книги и полки, аннотации и связей автора/жанра/серии.
- Повторный scan обычной, ZIP и INPX книги проверен на временной библиотеке.
  Web, OPDS, admin и скачивание проверены на искусственной книге с
  `DEBUG=False`.
- Test-only CI workflow разбирается как YAML; его шаги выполнены локально
  против отдельной PostgreSQL 17. Инструкции для worker аннотаций и
  [backup/restore/отката](operations.md) сохранены в репозитории.
- M06.2: клиент PostgreSQL 17.11 проверен; пробный backup/restore новой dev-БД
  с искусственными данными в отдельную БД и с копией библиотеки прошёл.
  Сохранность ID, пользователя, полки, связей, аннотаций и настроек, два scan,
  web/OPDS/download подтверждены. [Результаты и отклонения](m06-restore.md).
- M06.5c: отдельные private-настройки Django и шаблон Caddy подготовлены.
  134/134 теста прошли; `check`, проверка миграций и `collectstatic` успешны.
  Web/OPDS/download дали 200, HTTP redirect — 301 на восстановленной
  одноразовой БД при имитации заголовка HTTPS-прокси. Реальный TLS не проверен.
- M06.5g: реальный TLS на `192.168.88.44:8443` проверен с внутренним CA без
  обхода проверки сертификата. Web/OPDS/поиск/static дали 200, скачивание
  искусственной книги совпало побайтно. [Детали](m06-https-probe.md).

## Условия и непроверенные данные

- Пользователь выбрал новую установку без переноса прежней рабочей БД.
  Миграция прежней БД и сравнение её ID, пользователей, полок, связей и
  аннотаций неприменимы. Результат M06.2 относится только к искусственным данным.
- GitHub Actions не запускался удалённо: push в этом задании не выполнялся.
  Реальную OPDS-читалку проверяет пользователь.
- `manage.py check --deploy` с private-настройками оставил только
  `security.W004`: HSTS намеренно выключен до проверки реального HTTPS.
  `W008`, `W012`, `W016` устранены. Gunicorn и выдача static подготовлены, но
  Пользовательский Caddy на 8443 выпустил сертификат для выбранного IP; доверие
  CA и OPDS-читалка на другом устройстве ещё не проверены. Адрес может меняться
  между запусками через единую переменную `SOPDS_PRIVATE_HOST`; повторный выпуск
  при смене адреса отдельно не проверен. Постоянный сервис и порт 443 не настроены.
  [Контрольный список Django 5.2](https://docs.djangoproject.com/en/5.2/howto/deployment/checklist/)
  относит эти настройки к окружению размещения. Здесь deployment не выполнялся.

Кандидат проверен локально на искусственных данных; перечисленные внешние
проверки остаются условиями перед выпуском новой установки.
