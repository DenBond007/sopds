# Сопровождение встроенных компонентов

Эти компоненты не обновляются через Python uv.lock. Изменения принимаются только
после просмотра diff и соответствующих тестов; массовая замена с удалением миграций
недопустима.

| Компонент | Происхождение | Локальные изменения и проверка |
|---|---|---|
| `constance/` | django-constance 2.4.0; исходное обновление в истории SOPDS `30a401d` | Адаптация Django 5.2 в `27965fa`, исправления admin в `0a8b1b6`; тесты Constance, admin и сохранности значений после restore |
| `opds_catalog/zipf.py` | Совместимый fork Python zipfile; точная исходная ревизия не записана | История `baf6c40` и `27965fa`; сохраняет поддержку кодировки ZIP-имён, тесты ZIP/сканера/скачивания и повреждённых архивов |
| Foundation JS 6.2.4, jQuery 2.2.2 | Версии подтверждены заголовками поставляемых JS | Файлы в двух static-деревьях; полноценное обновление runtime требует тестов модальных окон, форм, меню и читалки |
| CSS toolchain | npm Foundation 6.2.4, Motion UI 1.2.2, Dart Sass; точные версии в package-lock | Новая воспроизводимая сборка заменяет Gulp/Bower; `npm run check` и Chromium smoke |

`python scripts/check_vendor.py` сверяет отпечатки отслеживаемых файлов с
`vendor-manifest.json`; `--write` нужен только после осознанного просмотра и тестов.
`git diff 30a401d..HEAD -- constance/` показывает собственные изменения Constance.
Наличие старого номера версии само по себе не является доказательством уязвимости.

Ежемесячно проверять Python, npm, GitHub Actions, базовые Docker images и внутренний
CA. Для Python сохранять проверенный uv.lock; для npm — package-lock. Dependabot
готовит ограниченное число предложений. После обновления: check, миграции, общий
набор, browser smoke и контроль сохранности данных. Не обновлять встроенную
Constance как обычный пакет без плана миграции её таблицы и настроек.
